# Automation Resume (A-RESUME)

Pembina **Resume** dan **CV** untuk pelajar diploma Malaysia, untuk permohonan latihan industri dan kerja pertama. Satu fail web (`index.html`), tanpa server: semua data kekal dalam pelayar pengguna.

- **Resume:** 1–2 muka, tajuk seksyen standard, satu lajur, hitam-putih, sesuai untuk ATS.
- **CV:** rekod akademik penuh (penyelidikan, pengajaran, penerbitan, geran, keahlian, rujukan).
- Resume Coach: senarai semak berasingan untuk Resume (18) dan CV (12).
- Muat turun PDF dan Word, cetak, backup `.json`, padam semua data pada peranti.

Nama asal: ResumeGo. Memori projek, spec dan keputusan: folder [`context/`](context/). Ujian: [`tests/`](tests/).
