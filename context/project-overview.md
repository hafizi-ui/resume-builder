# project-overview

| Perkara           | Isi                                                                                                                                                                                |
|-------------------|------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Apa               | Automation Resume (nama asal ResumeGo): pembina resume latihan industri satu muka A4 untuk pelajar diploma Malaysia, dengan semakan berpandu (Resume Coach).                       |
| Untuk siapa       | Pelajar diploma semester akhir di Malaysia, dari mana-mana institusi. Bukan untuk profesional berpengalaman atau eksekutif.                                                        |
| Aliran teras      | Pilih Resume atau CV → isi borang → semak Resume Coach → muat turun PDF. Muat turun sentiasa dibenarkan; skor hanya panduan.                                                       |
| Skop v1           | F-01 Sedia untuk pilot · F-02 PWA dan offline · F-03 Analytics minimum dan perkongsian · F-04 Resume atau CV (ditambah atas arahan pemilik, 15 Nov 2026).                          |
| Luar skop v1      | Akaun, simpan awan, semakan AI, bayaran, white-label, surat iringan, UI Bahasa Melayu, Google Play, App Store.                                                                     |
| Kriteria kejayaan | Pilot satu semester. Baseline: lawatan pertama, aktivasi, skor 80+, perkongsian; ditambah hasil temu bual. Sasaran angka selepas baseline.                                         |
| Tahap kedalaman   | **Alpha.** Setiap AC disemak pada apps yang berjalan di URL sebenar, dengan tarikh. Mana-mana feature yang menghantar isi resume ke server naik ke **GA**. Tahap hanya boleh naik. |
