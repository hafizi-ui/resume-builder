# architecture

| Perkara          | Isi                                                                                                                                                                                                                                                                                                                                                                                                                                                                               |
|------------------|-----------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------|
| Stack            | Satu apps web statik: `index.html` dengan CSS dan JavaScript biasa (tanpa framework, tanpa langkah build). Selepas F-02: tambah `manifest.webmanifest`, `sw.js`, `icons/` dan `vendor/` (jsPDF 2.5.1, docx 8.5.0, fon Figtree dan Carlito).                                                                                                                                                                                                                                       |
| Sempadan sistem  | Tiada server aplikasi. Satu-satunya trafik keluar yang dibenarkan selepas F-02 dan F-03: fail apps dari origin sendiri, dan acara analytics ke satu endpoint yang diluluskan pemilik.                                                                                                                                                                                                                                                                                             |
| Data             | Keadaan apps `{data, photo, showPhoto, isExample}` disimpan dalam `localStorage`. Kunci `automation-resume-v3`. Data versi lama (ResumeGo) tidak dipindah secara automatik kerana apps dihoskan di domain baharu yang tidak dapat membaca storan lama; pengguna lama membuka fail backup mereka (F-01 AC-6b). Keadaan juga menyimpan `docType` (resume atau cv). Tab terakhir dalam `sessionStorage`. Foto disimpan sebagai JPEG data URL 360×456. Tiada IndexedDB, tiada cookie. |
| Aliran render    | Input borang → `state.data` → `buildModel()` → satu model untuk pratonton, PDF (`makePDF`) dan Word (`makeDOCX`). Render ditangguh 120 ms selepas menaip.                                                                                                                                                                                                                                                                                                                         |
| Login            | Tiada.                                                                                                                                                                                                                                                                                                                                                                                                                                                                            |
| Skills berkaitan | context-kit (proses), app-marketing (pemasaran). onsenui-mobile-app **tidak** digunakan dalam v1.                                                                                                                                                                                                                                                                                                                                                                                 |
| Invariant        | \(1\) Isi resume tidak pernah meninggalkan peranti dalam tahap Alpha. (2) Pratonton, PDF dan Word datang daripada model yang sama. (3) Data pengguna tidak hilang semasa naik taraf versi. (4) Teks pengguna sentiasa di-escape sebelum dimasukkan ke HTML; foto hanya diterima jika bermula dengan `data:image/`.                                                                                                                                                                |
